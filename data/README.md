# Data Directory

This directory contains all data used in the machine learning projects.

## Structure

- **raw/**: Original, unmodified data as collected. Never modify files here.
- **processed/**: Cleaned and preprocessed data ready for model training.

## Guidelines

1. **Raw Data**: Store original datasets here without any modifications
2. **Processed Data**: Store cleaned, transformed data here for reproducibility
3. **Version Control**: Use meaningful names with versions (e.g., `dataset_v1.csv`)
4. **Documentation**: Include a `metadata.txt` file describing each dataset

## Data Management

- Keep file sizes reasonable
- Use consistent naming conventions
- Document data sources and transformations
- Maintain a data dictionary/schema
